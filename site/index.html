Run it in one command

npx ui-ux-suite .

You get a ranked list of located, measured, and fixed findings plus a weighted 0-10 score across 12 dimensions. No config, no API key, no network. Your code stays on your machine.

Install into your AI CLI

Recommended: one command for all your agents and projects.

npx skills add Aboudjem/ui-ux-suite -g

Works in 79 agents: pick yours in the menu (the list). npx skills is Vercel's open installer for agent skills. Its page: skills.sh/aboudjem/ui-ux-suite. Only this project: drop -g.

Or install straight into one agent: put it after -a (claude-code, codex, cursor, gemini-cli, github-copilot or opencode).

npx skills add Aboudjem/ui-ux-suite -g -a codex

Claude Code plugin: it adds 5 slash commands, 12 agents and the MCP server to the 14 skills.

claude plugin marketplace add Aboudjem/10x
claude plugin install ui-ux-suite@10x

The skills CLI installs the skills only. Add the MCP server, which the skills call, with one more line:

claude mcp add -s user ui-ux-suite -- npx -y ui-ux-suite --mcp

What it scores

Accessibility

WCAG 2.2 and APCA contrast, focus, labels, target size, reduced motion.

Color system

Contrast, duplicate hues, semantic roles, dark mode, OKLCH palettes.

Typography

Scale consistency, font count, body size, line height.

Layout and spacing

Grid, off-scale values, breakpoints, container widths.

Components and hierarchy

State coverage, scannability, information priority.

Interaction and polish

Animation timing, easing, feedback, shadow and radius tokens.

Located, measured, fixed

Most design-review tools tell you to improve your contrast. This tool tells you that .hero-subtitle at src/styles.css:14 is #fbfbfb on #ffffff = 1.03:1, which fails WCAG 1.4.3 AA, and to change the color to #767676 (4.54:1 on white) or darker. Each located finding names the file, line and selector, the measured wrong number, and the exact change, with a WCAG success criterion or a named UX law cited. 397 tests lock that specificity as a regression gate.
