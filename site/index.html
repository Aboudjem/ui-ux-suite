ESLint for design. It finds the exact line, the measured wrong value, and the exact fix, across 12 dimensions grounded in WCAG 2.2, APCA, and the Laws of UX.

Run it in one command

npx ui-ux-suite .

You get a ranked list of located, measured, and fixed findings plus a weighted 0-10 score across 12 dimensions. No config, no API key, no network. Your code stays on your machine.

Install into your AI CLI

One line links the ui-ux-suite skills into your CLI's skills directory. The MCP server is the universal fallback.

curl -fsSL https://raw.githubusercontent.com/Aboudjem/ui-ux-suite/main/install.sh | bash -s codex
claude mcp add ui-ux-suite npx ui-ux-suite --mcp

What it scores

Accessibility

WCAG 2.2 and APCA contrast, focus, labels, target size, reduced motion.

Color system

Contrast, duplicate hues, semantic roles, dark mode, OKLCH palettes.

Typography

Scale consistency, font count, body size, line height.

Layout and spacing

Grid, off-scale values, breakpoints, container widths.

Components and hierarchy

State coverage, scannability, information priority.

Interaction and polish

Animation timing, easing, feedback, shadow and radius tokens.

Located, measured, fixed

Most design-review tools tell you to improve your contrast. This tool tells you that .hero-subtitle at src/styles.css:14 is #fbfbfb on #ffffff = 1.03:1, which fails WCAG 1.4.3 AA, and to change the color to #767676 (4.54:1 on white) or darker. Every finding is located (file:line + selector), measured (the real wrong number), and fixed (the exact change), with a WCAG success criterion or a named UX law cited. 356 tests lock that specificity as a regression gate.
